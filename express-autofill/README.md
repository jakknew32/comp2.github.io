# Express AutoFill - โปรแกรมกรอกฟอร์มอัตโนมัติ

กรอก 6 ช่อง: เลขเอกสาร | วันที่ | รหัสลูกค้า | อ้างอิง | จำนวน | ราคา

## วิธีใช้ (เลือก 1 แบบ)

### แบบที่ 1: Python (แนะนำ - ใช้ง่ายสุด)
1. เตรียมไฟล์ Excel ตาม template `template.xlsx`
2. รัน `python express_filler.py`
3. เปิดโปรแกรม Express วางเคอร์เซอร์ที่ช่อง "เลขเอกสาร" ช่องแรก
4. กด Enter ในโปรแกรม Python มันจะพิมพ์ให้อัตโนมัติทีละแถว

### แบบที่ 2: AutoHotkey (ไม่ต้องลง Python)
1. ลง AutoHotkey จาก https://www.autohotkey.com/
2. ดับเบิ้ลคลิก `express_filler.ahk`
3. เปิดโปรแกรม Express วางเคอร์เซอร์ที่ช่องแรก กด F8 เพื่อเริ่มกรอก

## ไฟล์ Excel
- คอลัมน์ A-F = เลขเอกสาร, วันที่, รหัสลูกค้า, อ้างอิง, จำนวน, ราคา
- แถวแรกเป็นหัวตาราง เริ่มข้อมูลแถวที่ 2
